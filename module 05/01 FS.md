

### Лабораторная работа №14: «Управление дисками, разделами и файловыми системами»

**Цель работы:** Научиться создавать разделы на диске, создавать файловые системы, монтировать их вручную и автоматически при загрузке, а также использовать утилиты для диагностики.

**Теоретическая справка:**

**Основные понятия:**
- **Раздел (partition)** — логическая часть диска
- **Файловая система (filesystem)** — способ организации данных на разделе
- **Монтирование (mounting)** — подключение файловой системы к дереву каталогов
- **fstab** — файл `/etc/fstab` для автоматического монтирования

**Основные утилиты:**
- `fdisk` / `parted` — работа с разделами
- `mkfs.ext4` — создание файловой системы ext4
- `mount` / `umount` — монтирование/размонтирование
- `df` / `du` — просмотр использования дисков
- `fsck` — проверка файловых систем
- `blkid` — просмотр UUID устройств
- `lsblk` — просмотр блочных устройств

---

### Задание

Создайте новый раздел на диске, создайте на нём файловую систему, примонтируйте его вручную и настройте автоматическое монтирование при загрузке.

**Важно:** В учебных целях используем файл-образ (loop-устройство) вместо реального диска, чтобы не рисковать данными.

---

### Выполнение лабораторной работы (Вариант 1 - Базовый)

#### Шаг 1: Создание файла-образа для диска

```bash
# Создаем файл-образ размером 1 ГБ
sudo dd if=/dev/zero of=/tmp/disk.img bs=1M count=1024 status=progress

# Проверяем созданный файл
ls -lh /tmp/disk.img

# Подключаем loop-устройство
sudo losetup -f /tmp/disk.img

# Проверяем, какое loop-устройство создалось
sudo losetup -l

# Или проще — сразу указываем номер
sudo losetup /dev/loop0 /tmp/disk.img
```

---

#### Шаг 2: Создание разделов

```bash
# Просмотр информации о диске
sudo fdisk -l /dev/loop0

# Создаем GPT таблицу разделов с помощью parted
sudo parted /dev/loop0 mklabel gpt

# Создаем основной раздел размером 800 МБ
sudo parted /dev/loop0 mkpart primary ext4 1MiB 800MiB

# Создаем swap-раздел размером 200 МБ
sudo parted /dev/loop0 mkpart primary linux-swap 800MiB 1000MiB

# Создаем третий раздел (оставшееся место)
sudo parted /dev/loop0 mkpart primary ext4 1000MiB 100%

# Просмотр созданных разделов
sudo parted /dev/loop0 print

# Или через lsblk
lsblk /dev/loop0

# Подключаем разделы как loop-устройства
sudo kpartx -a /dev/loop0

# Проверяем, что разделы появились
ls -la /dev/loop0*
```

---

#### Шаг 3: Создание файловых систем

```bash
# Создаем файловую систему ext4 на первом разделе
sudo mkfs.ext4 -F -L LAB_EXT4 /dev/loop0p1

# Создаем swap на втором разделе
sudo mkswap -L LAB_SWAP /dev/loop0p2

# Создаем ext4 на третьем разделе
sudo mkfs.ext4 -F -L LAB_DATA /dev/loop0p3

# Проверяем созданные файловые системы
sudo blkid /dev/loop0p*
```

---

#### Шаг 4: Ручное монтирование

```bash
# Создаем точки монтирования
sudo mkdir -p /mnt/lab_disk
sudo mkdir -p /mnt/lab_data

# Монтируем первый раздел
sudo mount -t ext4 /dev/loop0p1 /mnt/lab_disk

# Проверяем, что примонтировалось
df -h /mnt/lab_disk
mount | grep lab_disk

# Создаем тестовые файлы
echo "Тестовый файл 1" | sudo tee /mnt/lab_disk/test1.txt
echo "Тестовый файл 2" | sudo tee /mnt/lab_disk/test2.txt
sudo mkdir /mnt/lab_disk/subdir
echo "Файл в поддиректории" | sudo tee /mnt/lab_disk/subdir/test3.txt

# Просмотр содержимого
ls -la /mnt/lab_disk

# Размонтируем (для демонстрации)
sudo umount /mnt/lab_disk

# Проверяем, что размонтировалось
mount | grep lab_disk
```

---

#### Шаг 5: Настройка автоматического монтирования (fstab)

```bash
# Получаем UUID разделов
sudo blkid /dev/loop0p1
sudo blkid /dev/loop0p3

# Сохраняем UUID в переменные (подставьте свои значения)
UUID1=$(sudo blkid -s UUID -o value /dev/loop0p1)
UUID3=$(sudo blkid -s UUID -o value /dev/loop0p3)

# Создаем резервную копию fstab
sudo cp /etc/fstab /etc/fstab.backup.$(date +%Y%m%d)

# Добавляем записи в fstab

UUID=<вставляем UUID1> /mnt/lab_disk ext4 defaults,noatime 0 2

UUID=<вставляем UUID2> /mnt/lab_data ext4 defaults,noatime 0 2

 /dev/loop0p2 none swap sw 0 0

# Проверяем содержимое fstab
tail -10 /etc/fstab

# Монтируем все разделы из fstab
sudo mount -a

# Проверяем, что все примонтировалось
df -h | grep lab
mount | grep lab
```

---

#### Шаг 6: Использование утилит

```bash
# 1. df - просмотр использования дисков
df -h
df -i
df -T

# 2. du - просмотр размера директорий
sudo du -sh /mnt/lab_disk
sudo du -h --max-depth=1 /mnt/lab_disk

# 3. lsblk - просмотр блочных устройств
lsblk
lsblk -f

# 4. blkid - просмотр UUID
sudo blkid

# 5. tune2fs - информация о ext4
sudo tune2fs -l /dev/loop0p1 | head -20

# 6. fsck - проверка ФС (не на смонтированной!)
sudo umount /mnt/lab_disk
sudo fsck -n /dev/loop0p1
sudo mount /dev/loop0p1 /mnt/lab_disk

# 7. stat - информация о файле
stat /mnt/lab_disk/test1.txt
```

---

#### Шаг 7: Проверка работоспособности

```bash
# 1. Проверка, что разделы смонтированы
df -h | grep -E "lab_disk|lab_data"

# 2. Проверка файлов
ls -la /mnt/lab_disk/
cat /mnt/lab_disk/test1.txt

# 3. Проверка swap
swapon -s
sudo swapon /dev/loop0p2
swapon -s

# 4. Проверка fstab
cat /etc/fstab | grep -A 5 "Лабораторной"

# 5. Проверка UUID
sudo blkid | grep loop0
```

### Команды для работы с разделами (шпаргалка)


```bash

parted /dev/loop0 mkpart primary linux-swap 800MiB 1000MiB
parted /dev/loop0 print
```

#### Создание файловых систем
```bash
mkfs.ext4 -F -L LABEL /dev/loop0p1
mkswap -L LABEL /dev/loop0p2
```

#### Монтирование
```bash
mount -t ext4 /dev/loop0p1 /mnt/lab_disk
umount /mnt/lab_disk
mount -a  # монтирование всех разделов из fstab
```

#### Просмотр информации
```bash
df -h
du -sh /path
lsblk -f
blkid
fdisk -l /dev/loop0
```

```bash
fsck -n /dev/loop0p1
tune2fs -l /dev/loop0p1
```
